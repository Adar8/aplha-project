# מערכת העיצוב של AlphaTrader

כל מסך, מודול או רכיב חדש באפליקציה חייב להיראות כמו חלק מאותו מוצר. הקובץ הזה הוא המקור היחיד לצבעים, לפונטים ולכללים. אם משהו כאן מתנגש עם בקשה של המשתמש, הבקשה של המשתמש קובעת, ואחרי זה מעדכנים את הקובץ.

## אופי

סינת'ווייב/סייברפאנק מאופק: רקע כחול־נייבי כהה, הדגשות ניאון זוהרות, תחושה של מסוף מסחר מודרני. מקצועי ולא צעצועי. הקהל: מתחילים בשוק ההון.

## צבעים

מגדירים את הצבעים כמשתני CSS ב־`:root` בלבד, ומשתמשים רק בהם. לא כותבים ערכי hex ישירות ברכיבים.

```css
:root {
  /* רקעים — נייבי כהה, אף פעם לא שחור */
  --bg:          #0B1020;
  --surface:     #121A33;
  --surface-2:   #1A2444;
  --border:      #26345C;

  /* טקסט */
  --text:        #E6ECFF;
  --text-muted:  #8A97C2;

  /* הדגשות ניאון */
  --turquoise:   #00E5D4;  /* פעולה ראשית, קישורים, פוקוס */
  --pink:        #FF2E97;  /* ירידה, הפסד, שגיאה, אזהרה חזקה */
  --purple:      #A855F7;  /* הדגשה משנית, תגיות, מצב פעיל */
  --lime:        #A3FF3C;  /* עלייה, רווח, הצלחה */

  --glow-turquoise: 0 0 16px rgba(0, 229, 212, 0.45);
  --glow-pink:      0 0 16px rgba(255, 46, 151, 0.45);
}
```

כללים:
- הרקע תמיד `--bg` (נייבי). אסור `#000` או שחור טהור.
- עלייה ורווח בליים, ירידה והפסד בורוד. לא מחליפים ביניהם באף מסך.
- כפתור ראשי אחד בכל מסך, בטורקיז. השאר משניים (מסגרת בלבד).
- לא מסתמכים על צבע בלבד: לצד צבע של עלייה או ירידה יש תמיד חץ או סימן (▲ ▼ או + −).
- זוהר (glow) רק על אלמנט אחד או שניים בכל מסך, אחרת הכול נראה צועק.

## פונטים

```html
<link href="https://fonts.googleapis.com/css2?family=Rubik:wght@500;700;800&family=Heebo:wght@400;500;700&family=JetBrains+Mono:wght@400;600&display=swap" rel="stylesheet">
```

| שימוש | פונט | משקל |
|---|---|---|
| כותרות | Rubik | 700–800 |
| טקסט רץ, כפתורים, טפסים | Heebo | 400–500 |
| מספרים, מחירים, תוויות נתונים, טיקרים | JetBrains Mono | 400–600 |

- כל מחיר, אחוז, כמות או טיקר מוצג ב־JetBrains Mono, כדי שהספרות יהיו מיושרות.
- גודל טקסט רץ מינימלי 16px. כותרת ראשית בסביבות 28–36px.

## עברית ו־RTL

- `<html lang="he" dir="rtl">` בכל עמוד.
- משתמשים במאפיינים לוגיים: `margin-inline-start`, `padding-inline-end`, `text-align: start`. לא `left`/`right`.
- מספרים, טיקרים ומונחים באנגלית בתוך משפט עברי עוטפים ב־`<bdi>` או ב־`<span dir="ltr">`, כדי שסימני מינוס, אחוז ודולר לא יקפצו לצד הלא נכון.
- גרפים וצירי זמן: הזמן זורם משמאל לימין גם באפליקציה בעברית (כמו בכל פלטפורמת מסחר). לא הופכים גרפים.
- אייקונים של כיוון (חץ "הבא", "חזרה") מתהפכים ב־RTL. אייקונים של עלייה/ירידה לא מתהפכים.

## רכיבים וריווח

- ריווח בכפולות של 4px (4, 8, 12, 16, 24, 32, 48).
- פינות: 12px לכרטיסים, 8px לכפתורים ושדות.
- כרטיס: רקע `--surface`, מסגרת `1px solid var(--border)`.
- אזור לחיצה מינימלי 44×44px. האפליקציה משמשת הרבה מטאבלט.
- פוקוס מקלדת גלוי: `outline: 2px solid var(--turquoise)`.
- תנועה עדינה בלבד (150–250ms), ומכבדים את `prefers-reduced-motion`.

## בדיקה לפני שאומרים "עדכנתי"

אסור לכתוב שהעיצוב עודכן בלי לראות אותו. אחרי כל שינוי ויזואלי:
1. מצלמים מסך של העמוד בעזרת הסקיל `webapp-testing` (Playwright), ברוחב טאבלט (1024px) וברוחב טלפון (390px).
2. מסתכלים על צילום המסך ומוודאים שהשינוי באמת שם ושה־RTL תקין.
3. רק אז מדווחים, ומצרפים את צילום המסך.
