# כתיבת טקסטים בעברית לאפליקציה

כל טקסט שהמשתמש רואה באפליקציה עובר לפי הכללים האלה. הקהל: אנשים שמתחילים ללמוד שוק הון, ובדרך כלל לא יודעים את המונחים.

## העיקרון

לכתוב כמו שמסבירים לחבר חכם שלא מכיר את התחום. עברית מדוברת, ברורה ופשוטה. אם משפט נשמע כמו תרגום מאנגלית, כותבים אותו מחדש.

## טון

- פונים בגוף שני. כדי לא לבחור בין זכר לנקבה, מעדיפים פעלים בציווי סתמי או צורות ניטרליות כשאפשר ("בחירת פקודה", "אפשר לנסות שוב"), ואם אי אפשר — זכר, באופן עקבי.
- חם ומעודד, בלי להתיילד. בלי סימני קריאה מיותרים ובלי אימוג'י בטקסט לימודי.
- אף פעם לא מבטיחים רווח ולא נותנים המלצה לקנות או למכור. זו אפליקציית לימוד.

## לא לתרגם מילולית מאנגלית

| לא ככה | אלא ככה |
|---|---|
| בצע את הפעולה | לביצוע / בצע |
| לחץ על הכפתור על מנת להמשיך | להמשך |
| אנא הזן את הסכום | כמה להשקיע? |
| ההזמנה שלך בוצעה בהצלחה | הפקודה בוצעה |
| קיימת שגיאה | משהו השתבש |
| על מנת ל־ | כדי ל־ |
| ביצוע של רכישה | קנייה |

- מעדיפים פועל על שם עצם ("כשקונים מניה" ולא "בעת ביצוע רכישה של מניה").
- משפט אחד = רעיון אחד. עד 20 מילים בערך.
- בלי "הינו/הינה". "הוא/היא" או כלום.

## סוגי טקסט

**כפתורים** — פועל קצר, 1–3 מילים, שאומר מה יקרה: "קנייה", "לשיעור הבא", "בדיקת תשובה". לא "אישור" ו"ביטול" כשאפשר להיות ספציפיים.

**כותרות** — אומרות על מה המסך, לא מתחכמות: "מה זה פקודת לימיט?"

**הסברים בשיעור** — קודם דוגמה מהחיים, אחר כך המונח. "נניח שאתה רוצה לקנות מניה של אפל, אבל רק אם המחיר יורד ל־$180. בשביל זה יש **פקודת לימיט**."

**הודעות שגיאה** — מה קרה + מה עושים. בלי להאשים את המשתמש ובלי קודים טכניים. "הסכום גבוה מהיתרה שלך. נסה סכום קטן יותר."

**מסך ריק** — מסביר למה ריק ומה הצעד הבא. "עוד לא ביצעת עסקאות. כדי להתחיל, בחר מניה מהרשימה."

**משוב בחידון** — נכון: אישור קצר + למה. לא נכון: בלי "טעית!"; אומרים מה התשובה הנכונה ולמה, בעדינות. "לא בדיוק. בפקודת שוק הקנייה מתבצעת מיד, במחיר הנוכחי."

## מספרים וסימנים

- מחירים בדולר: `$180.50`. בשקלים: `180.50 ₪`.
- אחוזים: `+2.4%`, `−1.1%` (מינוס טיפוגרפי). תמיד עם סימן.
- מספרים גדולים: `1.2 מיליון`, `3.5 מיליארד` — לא `1.2M`.
- טיקרים באותיות לטיניות גדולות: AAPL, TSLA.
- מספרים ומונחים באנגלית בתוך משפט עוטפים בקוד ב־`<bdi>` (ראו את סקיל מערכת העיצוב).

## מילון מונחים קבוע

משתמשים תמיד באותו מונח. בפעם הראשונה שמונח מופיע בשיעור, מוסיפים בסוגריים את המקור באנגלית.

| מונח באפליקציה | אנגלית | הערה |
|---|---|---|
| מניה | Stock / Share | |
| בורסה | Exchange | |
| פקודה | Order | לא "הזמנה" |
| פקודת שוק | Market Order | |
| פקודת לימיט | Limit Order | לא "פקודה מוגבלת" |
| פקודת סטופ | Stop Order | |
| סטופ לוס | Stop Loss | |
| מחיר קנייה מוצע | Bid | |
| מחיר מכירה מבוקש | Ask | |
| מרווח | Spread | |
| נזילות | Liquidity | |
| תיק השקעות | Portfolio | |
| פוזיציה | Position | |
| תנודתיות | Volatility | |
| מדד | Index | |
| דיבידנד | Dividend | |
| שווי שוק | Market Cap | |
| פיזור סיכונים | Diversification | |

מונח חדש שלא ברשימה: בוחרים את המונח שמקובל בעברית בפועל בקרב סוחרים ובאתרי בורסה ישראליים, מוסיפים אותו לטבלה, ומשתמשים בו מאז באופן עקבי.

## בדיקה לפני שמסיימים

- קוראים כל טקסט בקול (בראש). אם הוא נשמע כמו מכתב מבנק או כמו תרגום — משכתבים.
- בודקים שכל מונח תואם את המילון.
- בודקים שאין טקסט באנגלית שנשאר בממשק בטעות.
