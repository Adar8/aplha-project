# MATH 5 – אפליקציה אישית לבגרות במתמטיקה 5 יח"ל

יעד: ציון משוקלל 80 לפחות (היום 52: 581=58, 582=43) – דרישת הקבלה להנדסת חשמל ב-HIT.

## הפעלה

אפליקציית דפדפן סטטית, בלי שלב בנייה ובלי שרת צד-שרת.

```bash
cd math5
python3 -m http.server 8000     # ואז לפתוח http://localhost:8000
npm test                        # מתמטיקה, תקינות תוכן, בדיקות יחידה
npm run test:e2e                # בדיקות דפדפן (Playwright)
```

אי אפשר לפתוח את `index.html` ישירות מהקובץ (`file://`), כי מודולי JavaScript דורשים שרת. לטלפון: GitHub Pages על התיקייה `math5/`, או קישור Artifact.

## טכנולוגיה – ולמה

| בחירה | סיבה |
|---|---|
| HTML + CSS + JavaScript (ES modules), בלי framework | אפס התקנה ובנייה. כל שינוי תוכן נראה מיד. קל להעביר ל-React בהמשך אם יידרש. |
| KaTeX (מקומי ב-`vendor/`) | נוסחאות מתמטיות באיכות דפוס. נטען מקומית, ולכן עובד גם בלי אינטרנט. |
| localStorage + קובץ גיבוי JSON | שמירת התקדמות בלי שרת ובלי חשבון. הגיבוי מעביר התקדמות בין טלפון למחשב. |
| תוכן כקובצי JS (`js/data/lessons/*.js`) | ChatGPT יכול לכתוב שיעור לפי תבנית קבועה, וסקריפט בודק אותו. |

שלב הבא אפשרי: סנכרון ענן (למשל Supabase) כדי שההתקדמות תעבור אוטומטית בין מכשירים.
