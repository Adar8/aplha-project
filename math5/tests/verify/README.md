# חישובים בלתי תלויים לשיעורים

לכל שיעור חדש יש כאן קובץ `<lesson-id>.mjs` עם חישוב **בלתי תלוי** של כל תשובה מספרית בשיעור:
לא מעתיקים את ביטוי ה-`check` מהשיעור, אלא מחשבים בדרך אחרת (לולאה, בניית איברים, חיפוש בינארי, קואורדינטות, אינטגרציה נומרית).
`tests/verify-math.mjs` טוען את כל הקבצים כאן ומשווה לתשובה שבשיעור.

```js
export const expected = { 'my-lesson': { g1: 42, q1: Math.sqrt(2) } };
export const extra = [['example 1: max at x=2', /* bool */ true]];
```
