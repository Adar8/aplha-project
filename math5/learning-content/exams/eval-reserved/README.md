# חומר הערכה עצמאית (held-out)

**הקבצים בתיקייה הזו אסורים לגמרי על `lesson-builder` ועל `student-simulator`.** ראו `docs/quality-standards.md` §8.

## מה יש כאן
שאלונים (או שאלות ספציפיות) שמופו על ידי `exam-analyst` (אותו פורמט כמו `../blueprints/`: ניקוד, נושא, מיומנויות, תקציר — בלי נוסח רשמי מועתק), ששמורים **בכוונה** מחוץ להישג ידם של הסוכנים שכותבים תוכן ושל סימולציית התלמיד. המטרה: שכש-`independent-examiner` נבחן על חומר מהתיקייה הזו, התוצאה מודדת משהו אמיתי — לא "פתרון ששכתב מהדוגמה שראה בשיעור".

## מי כן יכול לקרוא
- `exam-analyst` (כתב את זה).
- `curriculum-architect` / `tools/audit.mjs` / `tools/gen-*.mjs` — למדידת כיסוי בלבד (לא לבניית תוכן).
- `math-auditor` — לבדיקת נכונות.
- `independent-examiner` — זה בדיוק מאגר ה"בחינה" שלו.
- המשתמש/סופרווייזר, לקריאה ישירה.

## מי אסור שיקרא
- `lesson-builder` — לעולם לא, גם לא "רק בשביל רעיון".
- `student-simulator` — לעולם לא.

## תוכן נוכחי (26.11.2026)
- `35571-2025-summer.json` — שאלון 35571 (קיץ תשפ"ה, מתכונת חדשה), 8 שאלות, 56 מיומנויות. הועבר הנה מ-`../blueprints/` ב-26.11.2026, **לפני** שאף `lesson-builder` ראה אותו — זה מה שהופך אותו לדגימת-ביקורת נקייה. הערה: שאלון 35581 (`../35581-2024-summer.json`) **אינו** שמור — הוא כבר שימש לתרגול אינטראקטיבי ול"הנבחן" מספר פעמים, אז הוא בחומר התרגול, לא בהערכה העצמאית.

## תחזוקה
אין לערוך קבצים כאן ידנית מלבד הוספת שאלון חדש על ידי `exam-analyst`/`curriculum-architect`. אחרי כל שינוי, להריץ `npm run gen:all` מ-`math5/` כדי ש-`docs/exam-catalog.json`/`docs/coverage-matrix.json` יתעדכנו (שניהם מסמנים `eval_reserved`/`reserved: true` בהתאם).
