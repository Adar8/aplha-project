# learning-content – מאגר השיעורים של MATH 5

כל שיעור הוא קובץ JSON אחד ב-`lessons/`. כדי שהשיעור יופיע באפליקציה, מוסיפים את שם הקובץ ל-`index.json`.
המבנה המלא מוגדר ב-`schema/lesson.schema.json`. דוגמה מלאה: `lessons/arithmetic-sequence.json`.

קבצים נוספים:
- `knowledge-map.json` – מפת מיומנויות: לכל מיומנות תחום, נושא בחינה, ידע מקדים ושיעורים מקושרים.
- `diagnostic.json` – שאלות מבחן האבחון. כל שאלה מקושרת למיומנות (`skill`), באותו פורמט כמו שאלת מבחן בשיעור.
  - `probes`: המיומנויות שנבדקות תמיד.
  - על כל טעות האבחון יורד לידע המקדים של המיומנות.

שיעור חדש מקושר למפת הידע: מוסיפים את מזהה השיעור לשדה `lessons` של המיומנות המתאימה.

## כללים למי שכותב תוכן (ChatGPT)

1. **טקסט:** עברית רגילה. מתמטיקה בתוך `$...$`, ונוסחה בשורה נפרדת בתוך `$$...$$`. להדגשה: `**מילה**`. בלי HTML.
2. **LaTeX ב-JSON:** כל לוכסן הפוך נכתב כפול: `"$\\frac{1}{2}$"`.
3. **שני סוגי שאלות בלבד:**
   - `numeric`: התשובה היא מספר אחד. `tolerance: 0` לתשובה מדויקת. אם התשובה מעוגלת, כותבים `tolerance` (למשל `0.02`) ו-`rounding` (למשל "שתי ספרות אחרי הנקודה").
   - `multipleChoice`: בדיוק 4 אפשרויות, ובדיוק אחת מהן עם `"correct": true`.
4. **`check` חובה בכל שאלה מספרית.** זה ביטוי חשבוני שמחשב את התשובה בדרך עצמאית, למשל `"20*(5+62)/2"`. הבודק מחשב אותו ומשווה לתשובה. מותר: `+ - * / ^ ( )`, `sqrt abs floor ceil round exp ln log`, `sin cos tan asin acos atan` (במעלות), `pi`, `e`.
5. **רמזים מדורגים:** מהכללי לספציפי. הרמז האחרון כמעט נותן את התשובה. במבחן הקצר אין רמזים.
6. **פתרון מלא:** `solution.steps` (צעד = פעולה אחת) ו-`solution.final`.
7. **טעויות נפוצות:** מגדירים ב-`commonMistakes`. מקשרים אליהן תשובות שגויות (`commonWrongAnswers`) או אפשרויות שגויות (`mistake`). כך האפליקציה יודעת להסביר ללומד *למה* טעה.
8. **סיווג מקור בכל שאלה:** `source.type`:
   - `original`: שאלה מקורית.
   - `official`: חובה `exam`, `year`, `session`, `questionNumber`, `url`.
   - `adapted`: חובה `basedOn` (אותם פרטים) ו-`changes` (מה שונה).
9. **מזהים קבועים:** ההתקדמות נשמרת לפי `id` של השיעור והשאלות. אחרי פרסום לא משנים אותם.

## בדיקה

```bash
node tests/validate-content.mjs                 # כל הקבצים שב-index.json
node tests/validate-content.mjs path/to/x.json  # קובץ אחד
node tests/validate-content.test.mjs            # מוודא שהבודק תופס שגיאות
```

הבודק דוחה קובץ כשיש בו:
- תשובה שלא מתאימה ל-check.
- LaTeX שלא מתרנדר.
- מספר שגוי של אפשרויות או של תשובות נכונות.
- הפניה לטעות שלא הוגדרה.
- מזהה כפול.
- שאלה רשמית בלי פרטי מקור.
- שאלה בלי פתרון.
